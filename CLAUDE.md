# Anno 117 Designer

Planificateur d'îles et de parties entières pour Anno 117 : React + TypeScript + Vite, moteurs
de plan dans `src/optimizer` et `src/commande`, planification d'un monde et import de
sauvegarde dans `src/monde`, données du jeu extraites dans `src/data`.

État, conventions, règles de jeu établies et suite du projet :

@docs/REPRISE.md

- feuille de route : `.claude/ROADMAP.md` ;
- mécanique du jeu, règles prouvées et questions ouvertes : `.claude/GAME_MECHANICS.md` ;
- conceptions et plans datés : `docs/superpowers/` (archives ; `.claude/AUDIT-*`, `PROGRESS.md`
  et `docs/ETAT-ET-SUITE.md` sont historiques).
